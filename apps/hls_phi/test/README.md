# Phi witnesses

These fixtures exercise the application actors, noise/correction loop, geometry, source-protocol placement and scheduler composition. Compiler-era whole-application interface/topology tests are retained here with `phi_source_` names; the compiler repository now exercises those APIs with small local semantic fixtures. EUnit runs without XLS. RTL benches and external-tool drivers exercise finite workloads separately and do not claim unrestricted correctness or physical-device operation.

`phi_spacetime_fixture` decodes accepted public frames from the finite N2 capture using the deployment codec, identifying all-coordinate step completions, readouts and actual stream stalls. It supplies workload interpretation to the generic [passive capture](../../../docs/hls_fabric/spacetime-capture.md).

`phi_line_owner.x.in` is a focused source-to-owner transition witness. Append it to a freshly emitted `phi_line_cell` owner (for example, `actors/actor_2.x` in the N2 repetition build) and run XLS `interpreter_main --warnings_as_errors=false --evaluator=ir-jit --compare=none` with that build’s DSLX search paths. It seeds completed reductions explicitly, then checks registered arithmetic, ordinary/final-round entry, blocked publication, last-drain admission and reset; it does not establish network reachability or routed timing. `phi_field_dslx:to_dslx/0` also emits finite arithmetic comparisons against the BEAM provider.
