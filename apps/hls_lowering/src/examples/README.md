# Small build walkthrough

[counter](counter/README.md) demonstrates the common build APIs with one tiny actor/topology and source-protocol, channel-scheduler and shared-RAM configurations. It remains a small build fixture. Complete decoder applications, their provider sources, host loops and hardware templates belong to [hls_phi](../../../hls_phi/README.md) and [hls_snowflake](../../../hls_snowflake/README.md), outside generic lowering.
