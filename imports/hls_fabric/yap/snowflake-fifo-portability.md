# Completion FIFO inference across synthesis tools

The first six-executor LUTRAM experiment preserved the result FIFO's original `did_push_occur` write predicate and passed bounded and full-width local simulations. Yosys inferred distributed RAM; Vivado did not. The matched full-core Vivado log emits Synth 8-7186 for every `buf__1` row: the `ram_style` attribute is ignored because the object is not inferred as RAM. Its 181,297 LUT / 151,354 FF result therefore does not measure the intended memory implementation.

Hypothesis before repair: the transformed FIFO still contains the unused generated row-update network, which reads every payload row at a constant address. Vivado diagnoses the RAM at elaboration, before its reported RTL optimization stages; Yosys removes the dead network before memory inference. Remove only this unused declaration and generate loop, requiring that no additional consumer exists. Keep the exact original control, payload read, reset gating and write predicate. Expect isolated Vivado to infer distributed RAM with the payload flip-flops removed; do not predict full-core timing or LUT savings until measured.

First counterfactual: synthesize the original and cleaned generated FIFO, both 32 bits and then full width (1,359 bits), using Vivado 2024.2, `xczu7ev-ffvc1156-2-e`, 5 ns, out-of-context synthesis. No placement or application-level clock claim. Separately rerun twelve-cycle symbolic checks, full-width mapped FIFO simulation and the ordinary full-core transcript checks. Immutable input hashes and isolated reports live under `_build/fifo-vivado-inference`; the corrected full-core release is `_build/fifo-completion-portable`.

The isolated paired measurements confirm the hypothesis. At 32 bits, removing only the dead read network changes 114 LUT / 201 FF / zero memory-LUT to 67 total LUT / 9 FF / 20 memory-LUT. At the actual 1,359-bit width, it changes 4,119 LUT / 8,174 FF / zero memory-LUT to 2,158 total LUT (1,380 logic, 778 distributed-memory LUT) / 15 FF. Both use the same five-entry logical FIFO, six physical rows, metadata and accepted-write predicate. The extra full-width control FFs are synthesis replication; payload storage is RAM. This verifies inference portability, not whole-core savings or timing.

The corrected release passes all six twelve-cycle symbolic FIFO checks and a 10,000-cycle full-width Yosys-mapped simulation: 3,704 simultaneous push/pop cycles, 3,249 stalls and seven resets with live contents. The transformation tests include explicit rejection of an additional consumer of the supposedly dead update network. Full-core replay and matched native measurements remain necessary before retaining the application variant. The isolated actual-width module is byte-identical to the corrected full-core release after module renaming.
