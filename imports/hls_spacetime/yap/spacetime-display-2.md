## Remaining display limits

Large structural cones still form dense pictures: opaque geometry cannot by itself disambiguate all unsensitized alternatives. Narrow windows, semantic/selection filters and the aggregate overview are explicit viewing choices, not missing retained data. Moving union/scene construction off the UI thread or preparing reusable GPU buffers is the next performance target if the measured pauses remain troublesome. Static cone-delay lightness is not dynamic criticality, individual-wire delay or step-time impact. Picking uses projected event/storage proximity with depth tie-breaking, not a pixel-perfect GPU picking buffer. Native positions remain tile-level memberships with schematic connecting spans. Browser readiness does not extend native mapping or simulation evidence.
