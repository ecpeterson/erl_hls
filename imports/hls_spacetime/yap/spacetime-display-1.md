# Unmapped geometry and label readability

2026-11-07. The clock stack now has a Show unmapped participants control, initially enabled. Turning it off suppresses unknown-location glyphs, unknown storage portions and dependency pairs with an unlocated endpoint. Placed portions of partial words remain. Compact symbols use selected-bit geometry for eligibility, so a mapped word centroid cannot locate an all-unknown access. Pair visibility is applied after pairing to avoid creating a false one-ended fan. Logical-only captures retain their lanes and disable this physical filter.

Labels are queued in screen coordinates, deduplicated and rejected on overlap or clipping. Clock-axis labels take priority; outgoing clipping labels use the destination boundary. Repeated word-dependency labels are removed from the canvas; their count remains in the summary. These changes affect drawing and hit targets only, not the event graph, traversal, inspector, recorded counts or native evidence.

Qualification: all 145 localized JavaScript tests passed, including nine new label/visibility fixtures. Browser syntax, pinned formatting and diff checks passed. A subsequent compact-mode eligibility review fix was checked with browser syntax and actual distributed/compact browser views; the helper tests already cover the all-unknown aggregate guard. Browser inspection of the retained 15-clock main example reduced 8,033 to 7,639 access glyphs, 1,730 to 510 dependency strokes and 944 to 900 storage strokes while preserving 521 events, 198 logical word-clocks and 21,756 installed cells. The RAM view kept 40 glyphs with the physical filter disabled. No browser warnings/errors, native jobs or recording replays. Erlang source and its previously passing checks are unchanged.
