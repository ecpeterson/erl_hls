# Application receive framing

Application streams carry complete 32-bit words. A header contains the payload length in words, transaction ID, flags, and operation tag; `TLAST` marks the packet's final accepted beat. A routed stream first carries a source/destination word. These checks concern accepted beats (`valid && ready`); pauses and backpressure do not advance assembly.

`axis::Rx`, `RxN`, and `ReservedRx` share one checked assembler. A packet produces exactly one `Frame` when its declared length fits the receiver and agrees with `TLAST`. Length zero requires `TLAST` on the header. Payload words occupy successive low-to-high 32-bit slices, with unused capacity zero-filled. The ordinary actor ABI holds three payload words; `RxN` selects a static capacity, with the wire length limiting packets to 255 payload words.

Early termination, late termination, and oversized declarations produce no application frame or reply. After rejection, the receiver stops updating its payload and count but keeps accepting beats through the actual `TLAST`. Header-looking payload words do not start new packets. A packet that never terminates requires an explicit link abort/reset; a length check cannot reconstruct a missing packet boundary.

The routing adapters similarly retain their route or discard decision through `TLAST`. Unknown destinations are drained without forwarding payload to any actor. `EndpointIngress` also checks the expected source. A route-only packet forwards no application header. A routing adapter does not need to assemble or validate the inner payload to discard an unknown route.

`ReservedRx` obtains one mailbox admission credit before accepting any packet beat. Rejected packets retain that reservation for the next valid frame. Only delivery of a valid frame transfers ownership of the reservation to the mailbox; rejection neither delivers a message nor consumes another credit. During output backpressure, the complete frame and its reservation remain held. Reset the receiver and credit owner together when abandoning a link session.

Generated `hls_gs` services also check a known callback tag's declared length against its record schema before unpacking or invoking the callback. A mismatch returns error code 3 (`{error, {remote_error, request_length}}` at the proxy), preserving the transaction ID and actor state. Both call and cast request tags receive this check. Public record schemas must be word-aligned and fit the three-word actor ABI. Callback failures and unsupported operation tags retain their separate error behavior. Generated `hls_statem` services have their own schema/phase dispatch validation after framing.

`axis::Beat` contains the word and `TLAST`, without a keep mask. Physical application wrappers currently require full-word inputs (`TKEEP = 0xf`) as a link contract; they do not enforce partial-word rejection. Transport fault reporting and keep-mask validation remain separate work. The passive debug monitor reports observed handshakes and framing observations; it is not an acknowledgement that an application frame reached a callback.

Run `bash tools/test_application_frames.sh XLS_ROOT` for interpreter/JIT checks and RTL simulations at three pipeline schedules. The RTL scenarios exercise length/capacity errors, unknown routes, long drains, reset, admission credit, stalled outputs, and generated service state conservation. The self-driving `DebugTop` fixture supplies rejected and valid packets to an admission-controlled receiver; `tools/test_topology_debug_integration.py` can inspect its blocked queues and wait dependencies through the public debug endpoint.
