# Snowflake through the ordinary actor compiler

Reviewed 2026-10-01. Completed original actor baseline. Shared execution, tree barriers and balanced arithmetic follow-ons have landed. [The service plan](decoder-service-investigations.md) owns larger-window and sustained-ingress qualification; [the campaign plan](topology-specialization.md) owns the current implementation. Earlier future-tense proposals below are historical.

The required baseline is a complete private Erlang actor application, lowered through `xls_parse:to_xls` and ordinary topology generation. No Snowflake transition, window protocol, barrier, queue or controller may be implemented in experiment-generated Verilog. Generic transport, clocks and simulation stimulus remain outside the application. Existing custom-RTL measurements are retained only as a different architecture.

Start with D3/H3, one phenomenological CSS sector. A vertex actor holds its node plus six incident-edge replicas; both endpoints derive identical next edge values from the same pair of endpoint contributions. Static geometry assigns exactly one reporter per retired edge. Old snapshots and a phase barrier preserve the reference's ordered N/W/D/U/E/S flooding; mailbox order does not choose that priority. A coordinator collects unique commit acknowledgments and owns the original drop/whole-grow/whole-merge/half-grow/half-merge sequence, merge budget and ordered sheet admission. Window shift messages explicitly carry the old upper layer, including boundary vertices without temporal edges. Correction messages include zero masks and retain their site identity and sheet tag.

Record types and kernel helpers remain ordinary source constructs. Add reusable acyclic nested-record support if needed; the private application may include the existing pure helper bodies while cross-module helper discovery remains separate. Do not add a custom `transpile/3` hook to hide the application.

Registered expectations before implementation: this actor baseline will be slower than the bespoke 3/5-clock phase engine. A quiet D3/H3 sheet alone requires 36×5=180 coordinator acknowledgments. At an ideal one input per clock, that port requires at least 1.44 µs at 125 MHz or 4.5 µs at 40 MHz, excluding neighbor traffic, fanout, callback latency and state feedback. Actual service must be measured; area and physical clock are not predicted from those message counts. The primary signal is a complete correct actor application and the dominant costs that it exposes, not an immediate 1 MHz result.

- [x] Validate a complete ERTS actor topology against reference round states, phase counts and every ordered correction site; check both endpoint edge replicas.
- [x] Exercise delayed/reordered neighbor arrival, startup races, duplicate/epoch rejection and finite output backpressure without host-selected phases.
- [x] Compile the same actors and topology normally, verify RTL corrections and round completion, and retain compiler/source identities.
- [x] Offer input independently of readiness, measure service/backlog/waiting with the existing profiler and Perfetto, and distinguish finite overload from stable service.
- [x] Measure complete-application area and native timing feasibility: XC7Z030 and ZU7EV both reject placement for capacity, so no routed or clock-qualified service claim is available. Retain synthesis estimates and capacity evidence.

The first transport carries at most 32 detector bits per input frame and the coordinator supports at most 255 vertices. These are explicit small-baseline bounds, not the final approximately 9-wide commit / 18–19-wide buffered spatial window. Larger barriers, input fragmentation, spatial handoffs and partition-quality validation remain future ordinary-actor work.

Input admission has eight logical credits, returned by actual `sf_round` output. The source retains all further nominal offers, with their original timestamps, and the profiler counts this backlog and credit waiting separately from wire backpressure. This leaves room in the coordinator mailbox for completion messages while future inputs are postponed. It is an explicit application contract; neither the oracle nor a host-selected phase schedule drives hardware progress. Tests must exercise all eight outstanding offers and delayed acknowledgments.

First functional gate: 22 EUnit tests pass, including all 11 named D3/D5 surface streams and 58 enumerated D3 streams (1,332 reference sheets), delayed neighbor/acknowledgment traffic, eight outstanding inputs, and focused identity/epoch/parity/retirement checks. Named ERTS cases compare complete node/edge state; RTL checks external corrections and completion epochs. These are separate finite witnesses, not a general correctness claim.

Source-level storage census before physical measurement: the vertex callback state is 679 bits (322 bits are its node plus six neighbor snapshots), with a 24-slot mailbox and at most six entry effects. The coordinator state is 482 bits with a 64-slot mailbox and one entry effect. These are compiler-interface widths, not FF/LUT counts: mailbox/outbox implementation and optimization must be measured. Keep geometry/configuration retention and communication storage separate from the minimal algorithmic node/edge state in area analysis.

The repeated D5 startup check exposed a race hidden by the first passing run: more than 64 ready messages could arrive before configuration and fill the postponed queue. Ready sources are now accumulated immediately in the barrier bitmap; arriving configuration validates that all belong to its population. Dedicated tests send 150 acknowledgments before configuration and reject an out-of-population early source. All 22 refreshed EUnit tests pass.

The first complete generated-RTL transcript matches eight burst inputs, all eight completion epochs and 45 site correction frames in source order. Its quiet round intervals are about 835 clocks, already much larger than the 180-clock acknowledgment-port lower bound. At the unqualified 25 ns simulation clock this is about 21 µs; physical implementation remains a separate measurement. Stage the exact validated RTL for one XC7Z030-1 and one ZU7EV-2 native implementation, each requested at 20 ns. This fixed-cycle comparison measures physical capacity/clock rather than predicting that a faster device alone can meet the one-microsecond goal.

Passive observations of existing service ports distinguish phase broadcast, vertex admission, committed completion publication and coordinator admission. In the eight-sheet control, all 36 vertex mailboxes have admitted a phase by 4–14 clocks after publication. Vertex completion publications span 8–42 clocks; coordinator acknowledgement admissions span 141–153 clocks, usually one every four clocks. The next phase follows the last admission by one clock (three across a sheet boundary). Thus the first bottleneck is the centralized completion intake, not broadcast fanout. The normal ingress alternates admission-token receipt with a selected-lane attempt; inspect that protocol before changing vertex arithmetic. Admission is not callback execution, and resource serialization is not a causal dependence between otherwise independent vertices.

Follow-on work, after establishing the complete baseline:

- [ ] Measure a reusable hierarchical completion barrier expressed in ordinary actors, comparing cycles and area against the same source cohort. Preserve source identity, duplicate rejection, busy aggregation and all-vertex commit semantics.
- [ ] Check whether the ordinary actor ingress can safely replace a consumed reservation immediately. Saturated cadence could fall from four to three clocks: at most 35 clocks saved across a 36-acknowledgement phase, before empty polling or late arrivals. Preserve occupied-plus-reserved capacity, fairness and registered credit publication; this is a component hypothesis, not a whole-round prediction.
- [ ] Compare the six sequential cluster-ID comparisons with a balanced, priority-preserving selection; retain full unrooting and equal-ID tie behavior. The reported synthesis path continues through actor commit gating, so kernel depth alone is not the full path.
- [ ] Revisit dedicated versus shared storage only with this complete actor workload; retained snapshots, message envelopes and queue depth must be charged alongside algorithm state.
- [ ] Extend source/mask capacity and spatial boundary protocols before making a claim about the intended large spatially parallel windows.

Completed baseline: 128 original sheets at 0.5% noise, mean 887.54 clocks between completed rounds (min 835/max 1385, population variance 16944.93), with 115 source-held sheets at peak. XC7Z030 synthesis uses 653646 LUT/207115 FF; ZU7EV uses 537999 LUT/207146 FF. Both fail placement capacity; no routed clock. An isolated service partitions 54.2% of primitive LUT cells into mailbox-only D/CE fanin, 32.3% shared with callback state. This supports targeting mailbox handling but is not a removable-area estimate.
