# Distributed memory development

The first complete witness uses D3 because its all-BEAM result is already established. Initial D2 CPU probes at noise/cutoff pairs `(0x80000000,16)`, `(0x40000000,8)`, `(0x80000000,4)` and `(0x20000000,4)` timed out; these do not establish impossibility of a smaller witness. Find a converging board-sized case independently before using it to measure capacity.

Startup embeds cutoff after each noise configuration. Live cutoff needs an acknowledged installation barrier or a separately justified delivery lead time; router acceptance alone is insufficient.

The routed host/gateway path uses actual fabric sessions and receipts. The physical FIFO/VPI adapter remains test-only. Attachment hashes configuration and bindings; it is single-use until reset, not a device-work fence or activation generation. Interrupted host work still requires a coordinated reset and a fresh physical byte-stream boundary before replacement.
