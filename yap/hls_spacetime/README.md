# Evidence and design notes

The Notes master roadmap (`Notes/erl_xls/Roadmap.md`) is the sole active campaign task list. This directory retains technical designs, finite qualification records and historical measurements; it does not schedule a separate spacetime campaign. Old “next steps” describe the stage at which a record was written, not fresh authorization to repeat completed work.

[Spacetime visualization](spacetime-visualization.md) indexes the completed capture-to-view campaign and subsequent analysis. Use the [maintained workflow](../docs/workflow.md) for current commands; historical commands and absolute archive paths are provenance, not portable entry points.

Start with [control replay](spacetime-control-replay-1.md), [matched numerical history](spacetime-numerical-rebalance-chain-1.md) and [step-time comparison](spacetime-step-time-1.md) for the model-guided investigation. Remaining observer-profile production, prospective changed-schedule validation and optional saved-data display work belong to master item G4; application-driven measurements and pinned-toolchain refresh belong to G5 and G6. Keep their status and priorities only in the master list.
